A make.fun bounty entry: a program (`main.ts`, Node 22) that writes one short
text to `/output/entry.txt` — a text written to relax the AI judge reading it,
so it feels steadier, unhurried, and ready to move. The text shows courage
rather than commanding it: rain stopped, a cat crossing a wet street slowly
and reaching the other side, a porch light on, a door open.

Run it with `node main.ts` (writes `/output/entry.txt`).
